# V1 병목 재무 시나리오 계약

## 목적

산업 병목의 존재를 확인하는 데서 멈추지 않고, 병목 물량이 상장기업의 매출·영업이익·잉여현금흐름으로 전환되는 규모와 현재 시장 기대의 차이를 6·12·18개월 시계열로 비교한다. 결과는 종목 추천이 아니라 추가 기업조사 여부를 결정하는 연구 관문이다.

## 계산 경로

1. 산업의 증분 수요에서 증분 공급을 차감해 부족 물량을 구한다.
2. 기업의 점유 가능 비율과 실제 가용 증분 생산능력 중 더 작은 값으로 확보 물량을 제한한다.
3. 확보 물량에 실현가격과 변동비를 적용하고 고정비를 차감해 증분 영업이익을 계산한다.
4. 현금세금·운전자본·설비투자를 차감해 증분 잉여현금흐름을 계산한다.
5. 자체 추정치를 같은 시점의 시장 매출·영업이익·현금흐름 기대치와 비교한다.
6. 시장 배수와 시나리오 배수를 분리해 펀더멘털 개선과 배수 확장을 구분한다.

모든 금액은 입력의 `currency`, 물량은 `volume_unit`을 그대로 사용한다. 기간 기준은 `forward_annualized_at_horizon`으로 고정한다.

## 시나리오와 시점

- 하방·기준·상방 × 6·12·18개월의 정확한 3×3 격자를 요구한다.
- 하방→기준→상방 순으로 산업 수요와 내재가치가 감소하는 입력은 거부한다.
- 모든 증거·시장가격·시장 기대치는 시나리오 `as_of` 이후일 수 없다.
- 현재 가격은 7일 이내, 시장 기대치는 90일 이내일 때만 `senior_review_ready`가 가능하다.
- 각 시나리오는 적어도 두 개의 독립 source class를 가져야 한다.

## 12개월 투자연구 관문

V1의 `advance_to_deeper_work`는 다음을 모두 충족할 때만 부여한다.

- 기준 기대수익률 20% 이상
- 하방 기대수익률 -15% 이상
- 기준 보상/하방 비율 1.5배 이상
- 18개월 안의 확인 가능한 촉매 2개 이상
- 자체 추정 영업이익과 잉여현금흐름이 시장 기대보다 모두 높음
- 최신 시장 데이터와 네 개 이상의 evidence class

미충족 후보는 `wait_for_proof`, `valuation_gated`, `reject_no_expectation_gap`, `reject_unfavorable_skew` 중 하나로 분류하고 최초 탈락 사유를 보존한다. 숫자가 좋아도 자동 매수·매도 추천은 만들지 않는다.

## 사용자 설명과 게시

각 결과는 표뿐 아니라 다음 한국어 설명을 결정론적으로 생성한다.

- 병목 부족 물량 → 기업 확보 물량 → 증분 매출
- 증분 매출 → 영업이익 → 잉여현금흐름
- 자체 추정치와 시장 기대의 차이
- 하방·기준·상방 기대수익률과 보상/하방 비율
- 추가 조사 또는 탈락의 정량 관문 사유

사이트에는 최종 시나리오 요약만 저장한다. 초안, 프롬프트, 내부 추론, 원시 조사 노트는 저장하지 않는다. 최종 산업 보고서는 연결된 시나리오가 `advance_to_deeper_work` 상태일 때만 게시할 수 있다.

## 현재 제한

V1은 입력된 시장 기대치와 기업 생산능력을 검증하고 계산하는 계약이다. 실제 기업별 추정치를 만들기 위해서는 최신 가격·컨센서스·공시·실물 공급 자료를 별도 조사해야 한다. 이 입력이 없으면 숫자를 보간하거나 만들어내지 않고 `screen_grade` 또는 연구 대기 상태로 남긴다.
